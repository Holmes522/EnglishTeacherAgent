# English Teacher AI Agent 开发任务清单

状态：Draft。以下任务按依赖排序；每项应在一个专注开发会话内完成，预计触及不超过 5 个主要文件。实际文件名可在脚手架后调整，但验收标准不得静默修改。

## 阶段 0：评审与 Spike

### Task 0.1：批准产品与架构基线

**描述：** 评审能力地图、PRD、技术设计和 4 份 ADR，关闭或明确分派开放问题。

**验收标准：**

- [ ] 目标用户、首发地区、匿名/账号范围和评分定位有明确结论。
- [ ] 文档状态、决策记录和变更历史一致。

**验证：** 产品、技术、QA、安全评审记录齐全，文档链接无断链。

**依赖：** 无

**预计范围：** S（文档）

### Task 0.2：双语词典/词库 Spike

**描述：** 对至少两个合法候选评估授权、中文义项覆盖、词性/形态/词族、版本、缓存和 SLA。

**验收标准：**

- [ ] 用 100 个词条生成覆盖率与字段映射报告。
- [ ] 选定 MVP 主数据源或明确阻塞与替代方案。
- [ ] 法务允许的展示、缓存和留存边界被记录。

**验证：** 固定样例可重复查询，结果能追溯到版本和源 ID。

**依赖：** Task 0.1

**预计范围：** M（Spike + 报告）

### Task 0.3：多模型质量/成本 Spike

**描述：** 使用初始黄金集比较至少两个供应商在例句、评改、中文解释、结构化输出、延迟和成本上的表现。

**验收标准：**

- [ ] 评测记录固定模型 ID、参数、提示词版本和运行日期。
- [ ] 选出 `QUALITY/BALANCED/FAST` 初始路由及可接受降级。
- [ ] 输出失败率、P50/P95、单位任务成本和质量分。

**验证：** 同一评测可由单条命令复现，结果不含密钥/敏感文本。

**依赖：** Task 0.1

**预计范围：** M

## 阶段 1：基础

### Task 1.1：初始化 monorepo 与质量命令

**描述：** 创建 pnpm workspace、Web/Worker/package 目录及 lint、typecheck、test、build 基线。

**验收标准：**

- [x] Node.js/Next.js/依赖准确版本和 lockfile 已提交。
- [x] strict TypeScript、格式化和环境变量 schema 生效。
- [x] README 中所有计划命令可执行。

**验证：** `pnpm lint && pnpm typecheck && pnpm test && pnpm build`。

**依赖：** Task 0.1

**预计范围：** M（脚手架机械文件不计业务文件上限）

### Task 1.2：定义并发布核心契约

**描述：** 实现 LearningRun、LearningItem、WordAnalysis、SentenceReview、PublicError 和能力清单 schema。

**验收标准：**

- [x] JSON Schema、TypeScript 类型和 OpenAPI 从同一来源生成。
- [x] 所有 union 有判别字段和 schemaVersion。
- [x] Unicode range、分数范围和批量上限有测试。

**验证：** `pnpm test --filter contracts`，生成文件无未提交差异。

**依赖：** Task 1.1

**预计范围：** M

### Task 1.3：建立任务持久化、outbox 和队列

**描述：** 建表、repository、outbox 发布和 Worker 领取/租约状态机。

**验收标准：**

- [ ] 事务同时写 run/items/outbox，崩溃恢复不丢任务。
- [ ] 至少一次投递下重复消费不产生重复结果。
- [ ] 状态转换拒绝非法跃迁。

**验证：** PostgreSQL/Redis 集成测试覆盖成功、崩溃、租约超时和重复消息。

**依赖：** Task 1.2

**预计范围：** M

### Task 1.4：创建 Learning Runs API 与 SSE

**描述：** 实现创建、查询、取消、重试和断线续传事件端点。

**验收标准：**

- [ ] 幂等键原子认领，同键不同请求体返回 422。
- [ ] SSE 事件有单调 ID，GET 资源是最终事实状态。
- [ ] 匿名会话不能读取其他会话任务。

**验证：** API contract + 集成测试；断线后用 Last-Event-ID 恢复。

**依赖：** Task 1.3

**预计范围：** M

### Checkpoint A：基础链路

- [ ] fixture 任务可从浏览器创建、Worker 完成并通过 SSE 显示。
- [ ] lint/typecheck/test/build 全绿。

## 阶段 1：核心纵向切片

### Task 1.5：实现输入拆分与意图识别

**描述：** 交付规范化、单词/句子/混合批量拆分、显式意图优先和低置信度澄清。

**验收标准：**

- [x] 支持换行、编号、项目符号、引号和中英混合。
- [x] 20 项/5000 字符上限不静默截断。
- [x] 原文、规范化文本和顺序全部保留。

**验证：** 单元 + 属性测试，覆盖 `tests/golden` 的 30 个解析案例。

**依赖：** Task 1.2

**预计范围：** M

### Task 1.6：实现词典适配器与单词查询切片

**描述：** 接入获批词典，完成词性分组、全部标准义项、来源与未收录行为，并在 UI 显示结果卡。

**验收标准：**

- [ ] 义项与基准词典字段一致，记录版本和源 ID。
- [ ] 未收录/拼写疑似错误不会伪造完整结果。
- [ ] 移动/桌面结果卡可读，可反馈。

**验证：** 100 词条 golden eval + 单词查询 E2E。

**依赖：** Task 0.2、1.4、1.5

**预计范围：** M

### Task 1.7：实现模型网关和两个供应商适配器

**描述：** 实现结构化生成端口、固定模型注册、路由、超时、有界重试、降级、用量和错误映射。

**验收标准：**

- [ ] 业务包没有供应商 SDK 类型/模型 ID。
- [ ] 非法响应被 schema 拒绝，密钥和原始错误不泄露。
- [ ] 主供应商限流时切换到已批准备用模型。

**验证：** 两个 provider contract suite + 故障注入测试。

**依赖：** Task 0.3、1.2

**预计范围：** M

### Task 1.8：实现义项绑定例句切片

**描述：** 基于指定词典义项生成默认/定制例句、翻译、难度和高亮。

**验收标准：**

- [ ] 默认 3 句且引用有效 senseId。
- [ ] 目标词/合理变形存在，语法和义项匹配检查通过。
- [ ] 数量、CEFR、场景和时态约束生效。

**验证：** 例句 golden eval + 查词到例句 E2E。

**依赖：** Task 1.6、1.7

**预计范围：** M

### Task 1.9：实现句子评分与纠错切片

**描述：** 按固定量表输出维度分、问题范围、解释、最小修正、自然改写和置信度。

**验收标准：**

- [ ] 总分等于分项和，所有范围有效。
- [ ] 正确句不被强制改写；风格建议不冒充错误。
- [ ] 最小修正尽量保持原意，低置信度展示假设。

**验证：** 120 句 golden eval + 句子评改 E2E，达到 PRD 指标。

**依赖：** Task 1.7

**预计范围：** M

### Task 1.10：实现词形与派生词族切片

**描述：** 展示适用屈折形式和经词库验证的派生词族，处理不规则/不存在形式。

**验收标准：**

- [ ] 屈折和派生分开展示，标签和词性正确。
- [ ] 无常用形式时明确说明，不强行造词。
- [ ] 罕见形式有频率/语域标识。

**验证：** 50 个词形 golden eval + 词形 E2E。

**依赖：** Task 1.6

**预计范围：** M

### Task 1.11：完成混合批量体验

**描述：** 把四条切片接入批量编排和 UI，支持渐进显示、保持顺序、取消与失败项重试。

**验收标准：**

- [ ] 20 项混合批次完成项即时显示。
- [ ] 单项失败产生 PARTIAL_SUCCESS，不影响其他项。
- [ ] 只重试失败项且不重复成功项的模型费用。

**验证：** 混合批量 E2E + 供应商故障/取消/重连测试。

**依赖：** Task 1.8、1.9、1.10

**预计范围：** M

### Task 1.12：接入可观测性、预算和反馈

**描述：** 增加 trace、RED/队列/质量/成本指标、限流预算、结果反馈和告警。

**验收标准：**

- [ ] run → item → 队列 → 供应商调用可追踪。
- [ ] 指标/日志无原文和密钥；成本可按任务与供应商聚合。
- [ ] 告警覆盖失败、延迟、队列年龄、校验失败和成本异常。

**验证：** 本地故障演练 + telemetry schema 测试 + 日志脱敏扫描。

**依赖：** Task 1.3、1.7

**预计范围：** M

### Task 1.13：能力预留与 MVP 发布门禁

**描述：** 实现 speech disabled、三类 locale、English LanguagePack、UI 插件槽位和 `/capabilities`，完成安全/可访问性/性能验收。

**验收标准：**

- [ ] 未启用语音不显示假播放，API 返回 NOT_ENABLED。
- [ ] 三类语言字段贯穿请求/结果；核心 UI 使用设计令牌/稳定槽位。
- [ ] PRD 全部 P0 指标和故障演练通过。

**验证：** contract + Playwright 可访问性/响应式 + 负载/安全测试报告。

**依赖：** Task 1.11、1.12

**预计范围：** M

### Checkpoint B：文本 MVP

- [ ] 四个核心功能、20 项批量和反馈 E2E 全绿。
- [ ] 黄金集、性能、成本、安全、隐私和无障碍门槛通过。
- [ ] 完成内部 → 5% 灰度发布准备。

**验证：** 权限/删除集成测试 + 学习闭环 E2E。

**验收标准：** 单词/例句/修正句支持英美音、语速、缓存和签名 URL；AI 合成标识清晰。

**验证：** 发音黄金集人工抽检 + provider contract + 缓存/权限测试。

**依赖：** Checkpoint B

**预计范围：** 应拆为供应商、存储、播放器三个 M 任务
