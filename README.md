# English Teacher AI Agent

面向中文学习者的英语教师 AI Agent。产品以“可靠的语言事实 + 可解释的教学反馈”为核心，支持单词释义、例句、词形/词族、英文句子纠错评分，以及一次输入多条内容的批量处理。

## 当前状态

项目目前处于需求与技术方案评审阶段，尚未进入编码。文档版本为 `v0.1 Draft`；评审确认后再按任务清单实施。

## 计划技术栈

TypeScript 单仓库、响应式 Web 前端、模块化单体 API、PostgreSQL、Redis/任务队列，以及可替换的词典、LLM 和语音供应商适配器。最终版本与依赖版本在项目脚手架任务中锁定。

## 计划命令

以下命令在脚手架完成后生效：

| 命令 | 用途 |
|---|---|
| `pnpm install --frozen-lockfile` | 安装锁定依赖 |
| `pnpm dev` | 启动本地开发环境 |
| `pnpm lint` | 静态检查 |
| `pnpm typecheck` | TypeScript 类型检查 |
| `pnpm test` | 单元与集成测试 |
| `pnpm test:e2e` | 端到端测试 |
| `pnpm build` | 生产构建 |

## 评审门槛

开始编码前需要确认：目标用户年龄段、首发地区与合规要求、首个双语词典的数据授权、首批模型供应商、预算/延迟目标，以及是否首版就需要账号体系。
