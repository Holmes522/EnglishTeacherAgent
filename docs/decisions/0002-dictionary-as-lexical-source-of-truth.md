# ADR-002：词典是词汇事实源，大模型负责教学生成

## 状态

Proposed

## 日期

2026-09-09

## 背景

用户要求列出单词全部中文义项、词性和变化。通用大模型不能稳定保证义项完整、形态真实或来源可追溯；直接生成会产生漏义和幻觉。

## 决策

选择一套经法务/产品批准、版本化且有权用于目标场景的双语词典/词库，作为义项、词性、形态和词族的事实源。LLM 可以基于这些事实生成易懂解释、例句和教学反馈，但不能新增未经验证的“标准义项”或词形。所有词汇结果记录来源与版本。

## 备选方案

### 只使用大模型

- 优点：接入快、自然语言体验好。
- 缺点：无法定义“全部”，不可追溯，升级后结果可能漂移。
- 未选原因：无法达到事实准确性验收。

### 同时合并多个词典

- 优点：覆盖面可能更广。
- 缺点：义项去重、授权、词性映射和冲突解决复杂。
- 未选原因：MVP 先建立一个清晰基准；多源融合留给 P1。

## 后果

- 阶段 0 必须先完成词典授权与覆盖率 Spike。
- 产品文案需要说明“全部”相对于具体词典版本。
- 词典不可用时可以降级为“未经词典验证的推测”，但不得伪装成完整事实。
